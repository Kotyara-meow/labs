# Лабораторная работа № 2 — регулярные выражения и unit-тестирование

**Вариант 18:** проверка и поиск синтаксически корректных MAC-адресов.

## О работе

Программа на Python проверяет, соответствует ли строка формату MAC-адреса, и находит такие адреса в произвольном тексте, локальном файле или тексте загруженной веб-страницы. Для проверки используются регулярные выражения, а корректность функций проверяется автоматическими unit-тестами.

## Возможности

- проверка одного MAC-адреса целиком;
- поиск MAC-адресов в тексте;
- поиск в текстовом UTF-8-файле;
- загрузка страницы по HTTP/HTTPS и поиск совпадений в её тексте;
- поддержка форматов `AA:BB:CC:DD:EE:FF`, `AA-BB-CC-DD-EE-FF` и `AABB.CCDD.EEFF`;
- обработка сетевых ошибок, тайм-аутов и проблем чтения файла;
- удаление повторяющихся совпадений без учёта регистра;
- автоматические тесты, в том числе с имитацией сетевых ответов, чтобы тесты не зависели от реального интернет-соединения.

Проверяется синтаксическая форма адреса. Программа не определяет, существует ли соответствующее устройство в сети, и не проверяет принадлежность адреса конкретному оборудованию.

## Требования

- Python 3.10 или новее;
- пакет `requests` для загрузки веб-страниц.

Установите зависимость из каталога `Laba2_regex`:

```bash
python -m pip install requests
```

## Запуск программы

Интерактивный режим:

```bash
python main.py
```

Демонстрация на примере `sample.txt`:

```bash
python main.py --demo
```

Указать другой файл можно так:

```bash
python main.py --demo --file путь/к/файлу.txt
```

Если пример находится в `docs/sample.txt`, используйте соответствующий путь, например:

```bash
python main.py --demo --file docs/sample.txt
```

## Запуск тестов

```bash
python -m unittest -v
```

Тесты проверяют корректные и некорректные адреса, поиск совпадений, чтение файлов и поведение при ошибках. Сетевые запросы в unit-тестах имитируются, поэтому для запуска тестов интернет не требуется.

## Регулярное выражение

Реализация использует регулярное выражение для трёх форматов MAC-адресов. Шестнадцатеричные символы могут быть в верхнем или нижнем регистре. При поиске применяются ограничения по соседним символам, чтобы не извлекать адрес как часть более длинной шестнадцатеричной последовательности.
