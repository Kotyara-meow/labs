# Учебные лабораторные работы по Python

Репозиторий объединяет две учебные работы по программированию на Python: объектно-ориентированную модель поликлиники и инструмент проверки/поиска MAC-адресов с использованием регулярных выражений.

## Содержание репозитория

| Работа | Тема | Что реализовано | Документация |
|---|---|---|---|
| **ЛР1** | ООП: модель поликлиники | Модель предметной области, операции добавления/поиска/изменения/удаления, обработка ошибок, сохранение и загрузка JSON/XML, UML-диаграмма | [README лабораторной № 1](Laba1_polyclinic/README.md) |
| **ЛР2** | Регулярные выражения и unit-тестирование | Проверка MAC-адресов, поиск в тексте, UTF-8-файлах и веб-страницах, тестирование автоматизированными тестами | [README лабораторной № 2](Laba2_regex/README.md) |

## Как начать работу

1. Откройте README нужной лабораторной по ссылкам в таблице выше.
2. Проверьте требования к версии Python и зависимостям.
3. Следуйте инструкциям по запуску программы и тестов.
4. В папке `docs/` соответствующей лабораторной находятся отчёт и дополнительные материалы, если они включены в репозиторий.
