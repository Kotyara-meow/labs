# Лабораторная работа № 1 — объектно-ориентированная модель поликлиники

## О работе

Учебный проект на Python, моделирующий предметную область поликлиники с использованием объектно-ориентированного программирования. Программа предназначена для демонстрации классов и связей между сущностями, базовых операций управления данными, обработки исключений и сериализации.

## Основные возможности

- представление сущностей предметной области поликлиники с помощью классов;
- операции добавления, поиска, изменения и удаления записей (CRUD);
- проверка входных данных и обработка ошибок;
- сохранение и загрузка данных в форматах JSON и XML;
- демонстрационный набор данных;
- UML-диаграмма классов в графическом и редактируемом форматах.

Все данные в демонстрационном наборе вымышлены. Проект не предназначен для хранения реальных медицинских или персональных данных и не является медицинской информационной системой.

## Структура папки

```text
Laba1_polyclinic/
├── README.md
├── main.py                 # Исходный код приложения
├── data/
│   ├── clinic.json         # Демонстрационные данные JSON
│   ├── clinic.xml          # Демонстрационные данные XML
│   └── clinic_data.txt     # Человекочитаемое описание данных
├── docs/
│   ├── report.docx         # Отчёт по лабораторной работе
│   └── TEST_RESULTS.txt    # Результаты проверки, если включены
└── uml/
    ├── uml_classes.png     # Диаграмма классов
    ├── uml_classes.svg     # Векторная диаграмма, если включена
```

Фактический набор файлов может немного отличаться в зависимости от версии, загруженной в репозиторий.

## Требования

- Python 3.10 или новее;
- внешние библиотеки для базового запуска не требуются.

## Запуск

Перейдите в каталог `Laba1_polyclinic` и выполните:

```bash
python main.py
```

Для создания демонстрационных файлов JSON/XML в каталоге данных:

```bash
python main.py --demo
```

При необходимости можно указать другой каталог данных:

```bash
python main.py --demo --data ./data
```

## Форматы данных

Программа поддерживает сохранение и загрузку JSON и XML. Это позволяет представить одну и ту же модель данных в двух форматах и продемонстрировать сериализацию и десериализацию.

## UML и отчёт

Диаграмма классов показывает основные сущности предметной области и отношения между ними.
